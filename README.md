# Metaliza · Cadastro de Cores

Sistema simples para cadastrar as fórmulas de cores das peças cromadas, no lugar do caderno.

## O que faz

- **Cores:** cadastrar, buscar, editar, duplicar, excluir e imprimir fórmulas por referência.
- **Recalcular:** informe quanto vai usar de um ingrediente (ex.: 5 L de verniz) e o sistema recalcula o restante. Há atalhos: metade, ×2, ×3 e ×5.
- **Ingredientes:** vernizes, bases, pigmentos, solventes etc. Tudo pode ser adicionado, editado ou removido.
- **Ajustes:** categorias e unidades (g, kg, ml, L, gotas…) totalmente editáveis, mais a cópia de segurança.

## Como usar

Abra o link do site (GitHub Pages) ou o arquivo `index.html` em qualquer navegador.

## Importante (versão de teste)

Nesta primeira versão, os dados ficam salvos **somente no navegador do computador onde foram digitados**. Outro computador ou celular não vê as mesmas cores.

- Use **Ajustes → Baixar cópia de segurança** com frequência.
- Para levar os dados para outro computador, use **Ajustes → Restaurar uma cópia**.
- Limpar os dados de navegação do navegador apaga as cores.

O próximo passo planejado é ligar o sistema a um banco de dados (Supabase), para todos verem os mesmos dados.
